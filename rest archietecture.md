REST (Representational State Transfer) is a style of designing APIs.

API=application programming interface



**Key principles of REST:**



* Client-Server → client (browser/app) talks to server via API.
* Stateless → each request must have all the information (server doesn’t remember previous requests).
* Uniform Interface → common way of accessing resources (URLs, HTTP methods).
* Resources → everything is treated as a resource (e.g., users, orders).
* HTTP methods:

&nbsp;  get

&nbsp;  put

&nbsp;  post

-->To test an API, you can use browser, curl, Postman, or Python scripts.
